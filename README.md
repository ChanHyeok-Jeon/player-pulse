# player-pulse · 유저 동향 아침 브리핑

> 매시간 공개 커뮤니티 글을 모으고, 정해진 요일·시각에 **중요도 순 유저 동향을 Slack 전체 채널로** 보냅니다.
> AI는 글마다 성격만 분류하고, 중요도는 **코드가 고정 기준으로** 정하며, 보내기 전에 **PM이 검토·수정**합니다.

| | |
|---|---|
| **기간** | 2026.10 |
| **성격** | 개인 프로젝트 (개발 PM 업무 자동화) |
| **데모** | https://chanhyeok-pm.cloud/pulse/ |

<br>

## 왜 만들었나

게임사 사업PM 인턴 때 커뮤니티 동향 파악 과제에 **약 2시간**이 걸렸고, 현업 담당자도 매일 아침 **20~30분**을 들여 정리해 공유한다고 들었습니다.
출시 후 모니터링에서 커뮤니티 반응을 매일 확인하는 일을 자동화해, PM은 **판단과 전달**에 시간을 쓰도록 하는 것이 목표입니다. 리포트 초안 한 건을 만드는 데 걸리는 시간은 실제 실행에서 **약 30~45초**입니다.

## 구조

```
[매시간 수집]  디시인사이드 이터널 리턴 마이너 갤러리 목록 · 스팀 커뮤니티 리뷰(한국어·영어)
               robots.txt가 허용한 공개 목록만, 작성자 정보 없이 제목·조회·댓글·추천·시각만 저장, 최근 7일만 보관
    ↓
[AI: 글 단위 분류]  Amazon Bedrock (Nova Pro) · 100개씩 병렬로 "종류 | 대상 | 감정 | 요지"
                    종류: 장애 · 버그 · 네트워크 · 운영 · BM · UX · 밸런스 · 콘텐츠 · 질문 · 잡담
    ↓
[코드: 묶기·검증·중요도]  같은 종류·대상끼리 묶음 (대상이 제각각인 버그는 '버그 제보 모음')
                          질문·잡담·커뮤니티 사이트 이야기 제외, 대상 이름이 실제로 들어간 글만 셈
                          AI가 글마다 주제에 정말 해당하는지 다시 판정 (본문을 못 열면 제목 기준)
                          고정 기준으로 5단계 + '왜 이 단계인지' + 원문 링크
    ↓
[PM 검토]  발송 30분 전 초안 → 관리자 화면에서 중요도·주제 이름·근거 링크·메모 수정, 주제 빼기
           중요도를 바꾸면 이유 필수, Slack에 'PM 조정'으로 표시, 수정 기록 보관
    ↓
[Slack]  검토 완료된 리포트만 예약 시각에 발송 (자동 전송을 켜면 검토 전 초안도 발송)
```

## 발송 규칙

- 기본: **월~금 09:00** (웹에서 시각·요일·자동 전송 변경 가능)
- 기간: 직전 발송 시각 ~ 이번 발송 시각. **월요일은 금요일 09:00 ~ 월요일 09:00 주말 동향**
- 08:00 밀린 글 수집 → 08:30 초안 → 09:00 발송 (검토 완료 또는 자동 전송일 때)
- **기간을 직접 정해 동향 받기**: 웹에서 시작~끝을 고르면 그 기간 초안을 만들고, 검토 후 발송 (발송은 관리자 키 필요)

## 중요도 기준 (순위가 아니라 고정 기준)

| 단계 | 기준 |
|---|---|
| ●●●●● 긴급 | 서버 다운·접속 불가·로그인 불가·결제 오류·계정 손실 글이 **2시간 안에 3건 이상** (여러 유저가 동시에 겪는 장애) |
| ●●●●○ 높음 | 버그·장애·네트워크 제보가 **3건 이상** 확인 → QA 재현 확인 필요 |
| ●●●○○ 보통 | 오작동 제보 1~2건, 운영·BM 요구 5건 이상, 같은 불만 8건 이상 |
| ●●○○○ 낮음 | 관련 글 3건 이상 |
| ●○○○○ 참고 | 그 외 |

- 밸런스·의견은 아무리 많아도 ●●●○○까지, 긍정 반응은 ●●○○○까지
- 같은 단계 안에서는 점수(글 수 + 반응×0.15 + 심각 키워드 글×2 + 부정이면 글 수×1.5 + 스팀 비추천×1.5) 순서

## 만들면서 고친 것

| 문제 | 원인 | 해결 |
|---|---|---|
| 리포트가 거의 다 '알렉스'(실험체) 이야기 | 심각 키워드 '렉'이 '알렉스' 안에서 걸림 (실제 언급은 7일 3만 건 중 0.4%) | '렉'·'핑'·'핵'을 단어 경계로 매칭 |
| 조용한 날에도 1위는 항상 '높음' | 같은 날 주제끼리 순위로 단계를 매김 | 성격별 고정 기준으로 변경 |
| 본인 정지 사유 문의가 '정지·제재 불만' 상위 | 질문과 운영 이슈를 구분하지 않음 | '질문'으로 분류해 제외 |
| 관계없는 글이 한 주제로 뭉침 | 수백 개 글을 AI가 한 번에 묶음 | AI는 글 단위 분류만, 묶기는 코드 |
| '알렉스 버프 요구'에 다른 실험체 글 | '버프'처럼 반응 단어만 겹쳐도 통과 | 대상 이름이 들어간 글만 셈 |
| 자동 결과를 그대로 발송 | 사람 판단 단계 없음 | 발송 전 PM 검토·수정, 조정 이유 표시 |
